# AutoSDLC Backend

NestJS + Prisma + PostgreSQL API. See the [repository root README](../README.md) for setup and Sprint 1 details.

## Scripts

- `npm run start:dev` — run with hot reload
- `npm run build` — compile to `dist/`
- `npm run lint` — ESLint
- `npm test` — unit tests
- `npm run test:e2e` — end-to-end tests (requires the Postgres container running)
- `npx prisma migrate dev` — create/apply a migration
- `npx prisma studio` — inspect the database
